# Nithitorn Kaosa-ard – Portfolion verkkosivusto
Portfolion linkki https://alexntrx.github.io/portfolio/

Tämä on henkilökohtainen portfoliosivusto.  
Sivusto esittelee projekteja sekä yhteystiedot.

---

## Mitä sivusto sisältää?

Sivustolla on neljä pääosiota:

1. **Projektit (Työnäytteet)**
   - Esittelee verkkosovelluksia ja ohjelmistoja.
   - Mukana ovat esimerkiksi:
     - **Pos-Ravintola**: Ravintolan kassa-, tilaus- ja keittiöjärjestelmä QR-tilauksilla.
     - **Ilmo**: QR-koodilla toimiva ilmoitusjärjestelmä tilojen huoltotarpeille.
     - **Mini-X**: Yhteisöllinen verkkosovellus ja keskustelualusta.
   - Voit selata projekteja nuolinäppäimillä tai painikkeilla.

2. **Osaaminen**
   - Lista teknologioista ja työkaluista.
   - Esimerkiksi verkkokehitys, ohjelmointikielet, tietokannat ja suunnittelutyökalut.

3. **Koulutus ja kokemus**
   - Tietoa opinnoista Samiedussa (tieto- ja viestintätekniikka, ohjelmistokehitys).
   - Tietoa aiemmasta työkokemuksesta ja harjoitteluista.

4. **Yhteystiedot**
   - Yhteydenottolomake, jolla voi lähettää viestin suoraan tekijälle.
   - Sähköpostiosoite, puhelinnumero ja linkki GitHub-profiiliin.

---

## Käytetyt tekniikat

Sivusto on tehty selkeillä ja moderneilla verkkotekniikoilla:

- **HTML5**: Luo sivuston rakenteen ja sisällön.
- **CSS3**: Vastaa sivuston ulkoasusta, väreistä ja asettelusta. Sivusto toimii hyvin sekä tietokoneella että puhelimella.
- **JavaScript (Vanilla JS)**: Hoitaa sivun toiminnot, animaatiot ja projektien selaamisen.
- **Formspree**: Vastaanottaa ja välittää yhteydenottolomakkeen viestit sähköpostiin.


## Miten sivustoa käytetään paikallisesti?

Voit avata sivuston omalla tietokoneellasi helposti:

1. **Lataa tai kloonaa projekti:**
   ```bash
   git clone https://github.com/AlexNtrx/portfolio.git
   ```
2. **Avaa kansio:**
   - Siirry kansioon `portfolio`.

3. **Avaa sivu selaimessa:**
   - Tuplaklikkaa tiedostoa `index.html` tai avaa se verkkoselaimella (kuten Chrome, Edge tai Firefox).
   - Voit myös käyttää koodieditorin lisäosaa, kuten VS Coden **Live Serveriä**.
